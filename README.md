# Python Workshop

Welcome to the Python Workshop.

This repository contains the exercises and application code used during the workshop.

## Getting Started

You do not need to install Python or VS Code on your computer.

We will use **GitHub Codespaces** to provide a ready-to-use Python development environment.

### 1. Open the Repository

Open the workshop repository on GitHub:

https://github.com/chetanadhikary/python-workshop-student

### 2. Start GitHub Codespaces

On the repository page:

1. Click **Code**
2. Select **Codespaces**
3. Click **Create codespace on main**
4. Wait for the environment to finish loading.

A browser-based VS Code environment will open.

### 3. Check the Python Environment

Open the VS Code terminal and run:

```bash
python --version
